# SplitSmart – Smart Bill Splitting

SplitSmart is a web-based bill-splitting application designed to make sharing expenses easier, faster, and more organized. It aims to help friends, roommates, families, and groups calculate shared expenses without the confusion of manual calculations.

With features planned around receipt scanning and live synchronization, SplitSmart aims to make group expense management more convenient and transparent.

## ✨ Features

- **Bill Splitting:** Calculate and divide shared expenses among group members.
- **Receipt Scanning:** Designed to support receipt scanning for easier expense entry.
- **Live Synchronization:** Designed to keep shared expense information updated across users.
- **Simple User Interface:** Clean and user-friendly interface for managing expenses.
- **Expense Transparency:** Make it easier for group members to understand shared costs.
- **Responsive Design:** Build a consistent experience across different screen sizes.

> Note: Feature availability depends on the current implementation of the application.

## 🚀 Getting Started

Follow these steps to run SplitSmart locally.

### Prerequisites

- A modern web browser.
- Visual Studio Code (recommended).
- The Live Server extension for VS Code (optional).

### Installation

1. Clone the repository:

   ```bash
   git clone https://github.com/varshitha-3705/SplitSmart.git
   ```

2. Open the project folder:

   ```bash
   cd SplitSmart
   ```

3. Open the folder in Visual Studio Code.

4. Open `index.html` in your browser, or use the Live Server extension to launch the application.
